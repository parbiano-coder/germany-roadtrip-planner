렌터카 준비 가이드

픽업 카운터에서 당황하지 않으려면 서류와 보험 조건을 미리 확인해두세요.

필수 서류

  • 여권 (유효기간 6개월 이상)
  • 한국 운전면허증 원본
  • 국제운전면허증 (제네바협약)
  • 예약 확인서
  • 예치금 결제용 신용카드 (본인 명의, 엠보싱)

나이 · 예치금

  • 대여 가능 연령 보통 만 21~25세 이상, 업체별 상이
  • 26세 미만은 영young driver 추가요금 붙을 수 있음
  • 예치금(보증금) 300~1,500유로 카드 한도로 홀딩
  • 반납 후 3~4주 내 자동 환불

보험

  • 기본 자차보험(CDW) 자기부담금 확인 — 보통 750~1,500유로
  • 완전자차(Super CDW / 자기부담금 0) 추가 권장
  • 유리·타이어 보험(Glass & Tire) 옵션 확인
  • 국내 카드사 렌터카 자차보험 특약 여부 사전 확인

차량 인수 체크

  • 외관 흠집·기스 사진/영상으로 기록
  • 연료 정책 확인 (보통 Full-to-Full)
  • 연료 타입 확인 — 디젤(Diesel) vs 가솔린(Benzin), 주유구 라벨 확인
  • 삼각대·형광조끼·구급함 비치 여부 (법적 의무 비품)
  • 내비게이션/하이패스 단말기 유무
이 페이지는 여행 준비를 돕기 위한 참고 자료입니다. 실제 약관·요금은 렌터카사·예약 시점 기준으로 다시 확인하세요.
